1. Overview

P&ID Link connects your AutoCAD Plant 3D P&ID data with your Autodesk Revit model and keeps the two synchronised as the project develops. Rather than a one-time export, each connection is a persistent, two-way link that you can sync again whenever the data changes.

The add-in installs into both Revit and AutoCAD Plant 3D and adds a P&ID Link ribbon tab to each. You work from whichever application is convenient: pick a component in one, pick its counterpart in the other, and link them. From that point on you can review links, jump between partnered components, and carry Plant 3D attribute values across into Revit shared parameters.

Core ideas

  • A link joins one Plant 3D P&ID component to one Revit MEP element. Links persist between sessions.
  • Both applications show an Element List — an overview of what is and is not linked, with filtering and click-to-zoom.
  • Attribute values flow from Plant 3D into Revit. You map Plant 3D attributes to Revit shared parameters, then sync.
  • Only linked components take part in export and sync, so you move exactly the data you intend.

2. Installation

If you obtained P&ID Link through the Autodesk App Store, the installer is provided by Autodesk and places the add-in automatically for every supported version found on your machine. Run it and restart Revit and AutoCAD Plant 3D.

After installation, open either application and confirm the P&ID Link tab appears on the ribbon. The add-in loads automatically at start-up; there is nothing to load manually.

Plant 3D only. On the AutoCAD side, P&ID Link is intended for AutoCAD Plant 3D. It will not add its ribbon to plain AutoCAD or to other AutoCAD-based products.

4. Before you start — shared parameters

P&ID Link copies Plant 3D attribute values into Revit shared parameters. It does not create these parameters for you — they must already exist in your Revit project before mapping will work. Setting them up correctly once, at the start, avoids the most common difficulties.

Two prerequisites

1. Create and bind the shared parameters. Using Revit's Shared Parameters and Project Parameters tools, create the parameters you want to receive Plant 3D data and bind them to the relevant categories (for example Mechanical Equipment, Pipe Accessories, and the other categories listed in the appendix).

2. Place at least one element that carries all of them. Revit only exposes a shared parameter once an element using it exists in the model. Place at least one element that carries every shared parameter you intend to map, so that P&ID Link can see them all when you open Param Mapping. Without this, some parameters will not appear in the mapping list.

Why this matters. If a parameter you expect is missing from the mapping dialog, it is almost always one of these two steps: the parameter is not bound to the element's category, or no placed element yet carries it.

5. Linking components

A link is made by remembering one component in each application, then confirming the link. You can start from either side.

Step 1 — Pick in Plant 3D. Select the P&ID component and click Pick on the P&ID Link tab. The component is now remembered.

Step 2 — Pick in Revit. Select the corresponding MEP element and click Pick Element. That element is now remembered.

Step 3 — Link. Click Link in either application. The two remembered components are joined, and the picks are cleared ready for the next pair.

The order does not matter — you may pick in Revit first and Plant 3D second. What matters is that one component is remembered on each side before you click Link.

Which Revit elements can be linked. Links are supported for the major MEP equipment, fixture, device and accessory categories — see the full list in the appendix. Linear elements such as pipes and ducts are not linkable.

6. The Element List

Each application provides an Element List — an overview window listing the relevant components and showing, at a glance, which are linked. Open it from the Element List button on the ribbon.

What it shows

  • A Link column marking which components are currently linked.
  • Descriptive columns (such as Tag, Type, Category and Description) to help you identify each component.
  • A count of total components and how many are linked.

Filtering and zooming

  • Click any column header to filter the list by that column's values. A filtered header is highlighted, and Clear Filters resets it.
  • Click any row to zoom to that component. From Revit, the view zooms to the Plant 3D partner; from Plant 3D, to the Revit partner — a quick way to locate a component's counterpart in the other application.

7. Mapping and syncing attribute values

Once components are linked, P&ID Link can carry Plant 3D attribute values into the mapped Revit shared parameters. This is a three-part workflow: export the attribute names, build the mapping, then export values and sync.

One-time setup

1. Export the attribute names (Plant 3D). Click Export Attributes. This makes the Plant 3D attribute names available so you can map against them in Revit. Repeat this only when new attributes are introduced.

2. Build the mapping (Revit). Open Param Mapping. For each Plant 3D attribute you want to carry across, choose the Revit shared parameter it should populate, and click Add / Update. Remove a pairing with Remove selected.

Each time you sync

3. Export the values (Plant 3D). Click Export Values for the current sheet, or Export All to cover every sheet including closed ones. Only the values of linked components are exported.

4. Sync (Revit). Click Sync Params. The exported values are written onto the mapped shared parameters of the linked Revit elements. A summary reports how many elements and parameters were updated, and lists any that could not be written.

Read-only parameters. Some Revit parameters are calculated by Revit itself (for example Area) and cannot be written by any add-in. If you map an attribute to such a parameter, the sync summary will report it as read-only and skip it. To store an imported value, map it to a writable shared parameter with a different name.

8. Unlinking

To remove a link, remember both halves of the pair — pick the element in Revit and its partner in Plant 3D — then click Unlink in either application.

Unlink acts only when both sides are picked and the two picks belong to the same link. If they do not, the operation is refused and nothing is changed, so you cannot accidentally break the wrong link. When a link is removed from the Revit side, the mapped Revit parameters on that element are cleared, leaving no orphaned values behind.

9. Deleting components (self-heal)

If you delete a linked component in either application, its link becomes stale. P&ID Link cleans these up automatically: open the Element List in the application where you deleted the component, and any link whose component no longer exists is removed. Opening the other application's Element List then reflects the change.

A simple rule to remember: after deleting, open the Element List on that side. That is the moment each side re-checks reality and tidies up.

10. Licensing

P&ID Link is a one-time purchase with a perpetual licence. Your purchase includes all updates within this version and support for Revit and AutoCAD Plant 3D 2024–2027. There is no recurring subscription.

When obtained through the Autodesk App Store, access is tied to the Autodesk account that purchased the app. Sign in to that account in Revit and AutoCAD Plant 3D and the add-in loads normally — there is nothing to activate and no licence key to enter.

Working offline

At start-up the add-in checks your licence with the Autodesk App Store. The result is remembered on your computer, so you can continue working when you are offline or the service is unavailable. If the licence has not been verified for 14 days, the add-in will ask you to reconnect and sign in once.

If you are asked to sign in. Make sure you are signed in to Revit or AutoCAD Plant 3D with the same Autodesk account that purchased P&ID Link. If the account is correct and the message persists, contact info.dev4revit@gmail.com.

11. Troubleshooting

SymptomLikely cause and fix
The P&ID Link tab does not appear.Restart the application after installation. On the AutoCAD side, confirm you are in AutoCAD Plant 3D, not plain AutoCAD.
A shared parameter is missing from Param Mapping.The parameter is not bound to the element's category, or no placed element yet carries it. See section 4.
Sync reports a parameter as read-only.The target is a Revit-calculated parameter (such as Area). Map to a writable shared parameter with a different name.
Unlink does nothing.Both sides must be picked and belong to the same link. Pick the element in Revit and its partner in Plant 3D, then Unlink.
A deleted component still shows as linked.Open the Element List on the side where you deleted it; the stale link is then removed. See section 9.
A message says the licence could not be verified.Sign in to your Autodesk account using the account that purchased the app, and make sure the machine can reach the internet. See section 10.
Values do not appear after Sync.Confirm you exported values in Plant 3D first (Export Values or Export All), and that the components are linked — only linked components are exported.
