P&ID Link

Bidirectional linking between AutoCAD Plant 3D P&ID components and Revit elements

P&ID Link installs as a pair of add-ins: one for Revit and one for AutoCAD Plant 3D. Both must be installed, and both applications should be open at the same time for linking and navigation to work.

1. Introduction

P&ID Link connects P&ID components in AutoCAD Plant 3D drawings to elements in a Revit model. Once two objects are linked, the pair is remembered permanently, and you can move between them, keep track of which objects are already linked, and copy P&ID data into Revit parameters.

Typical uses

  • Keeping a P&ID and a Revit model in agreement about the same equipment.
  • Carrying tag numbers, service descriptions, line numbers and manufacturer data into the model without retyping them.
  • Checking, at a glance, which components have not yet been coordinated.

What is linked

On the Plant 3D side, P&ID Link works with P&ID components — the objects that carry data in the project database. Pipe and signal lines are excluded where components are listed.

On the Revit side it works with these categories: Mechanical Equipment, Pipe Accessories, Electrical Equipment, Electrical Fixtures, Data Devices, Duct Accessories, Fire Alarm Devices, Lighting Devices, Lighting Fixtures, Mechanical Control Devices, Plumbing Equipment, Plumbing Fixtures, Security Devices, Sprinklers and Telephone Devices.

Plain AutoCAD P&ID Link requires AutoCAD Plant 3D, because it reads the P&ID project database. To link attributed blocks in plain AutoCAD or its toolsets, use our separate product, CAD Link.

3. Installation

  1. Close Revit and AutoCAD Plant 3D.
  2. Run the installer obtained from the Autodesk App Store listing and follow the prompts.
  3. Start Revit or Plant 3D. The add-in loads automatically.

In Revit a ribbon tab named P&ID Link appears with the Linking, Overview, Mapping and Info panels. In Plant 3D a ribbon tab appears with a single Link panel.

To uninstall, use Windows Settings › Apps. Saved links and mappings are not removed by the uninstaller.

4. Licensing and license verification

P&ID Link is licensed per Autodesk account. The license is tied to the Autodesk account that acquired the app from the Autodesk App Store, so you should be signed in to that account in Revit and Plant 3D.

How verification works

When the add-in starts, it contacts the Autodesk licensing service to confirm that your signed-in account is entitled to use P&ID Link. The add-in sends only your Autodesk user identifier and the application identifier of P&ID Link. No drawing data, model data, file names or personal documents are transmitted.

Working offline

  • After a successful check, P&ID Link continues to work without an internet connection for 14 days.
  • From five days before that period ends, a reminder appears at start-up.
  • If the service cannot be reached and the 14 days have passed, the commands stop working until the next successful verification.
  • If the service replies that the account is not entitled, the commands stop working immediately.

When P&ID Link is blocked, the About / Privacy button remains available, so you can always read the privacy information and find the support address.

Privacy The full privacy policy, including the license verification described above, is published at privacy-pidlink.html.

6. Creating your first link

A link always joins exactly one P&ID component to exactly one Revit element. The order of the first two steps does not matter.

  1. Pick in Plant 3D — click Pick and select a P&ID component. P&ID Link confirms the handle and tells you whether it is already linked.
  2. Pick in Revit — click Pick Element and select an element of one of the supported categories.
  3. Link — click Link on either side. You only need to click it once, on one of the two sides.
One to one If either object is already part of another link, the earlier link is replaced. This keeps every component and every element in at most one pair.

Removing a link

Unlinking is deliberately strict. Both sides must be picked, and the two picked objects must belong to the same link. If only one side is picked, or the two picks are not partners, nothing is removed and a message explains why.

When a pair is removed, any Revit parameters filled through the mapping are cleared, so no stale values are left behind in the model.

7. Navigating between linked objects

  • Picking a linked component in Plant 3D makes Revit select and zoom to the linked element.
  • Picking a linked element in Revit makes Plant 3D zoom to the linked component.
  • Clicking a row in the Element List does the same.

Drawings that are not open

If the linked component is in a drawing that is not currently open, Plant 3D opens that drawing and then zooms to it. If the drawing has been moved or renamed, a message reports that it could not be found on disk.

Elements on closed worksets

In a workshared Revit model, if the linked element is on a workset that is not currently open, Revit opens that workset in order to show the element. The workset stays open for the rest of the session.

Both applications must be running Navigation works by passing a short request between the two add-ins. If the other application is closed, the request waits and is carried out the next time that application is running with P&ID Link loaded.

8. Parameter mapping and sync

  1. Export the attribute names — in Plant 3D click Export Attributes. Repeat this if you introduce components with new attributes.
  2. Define the mapping in Revit — click Param Mapping, choose a Revit shared parameter and a Plant 3D attribute, click Add / Update, then Save. Mappings are stored per Revit project.
  3. Export the values — click Export Values for the active drawing, or Export All to cover every drawing referenced by the links in one pass.
  4. Sync in Revit — click Sync Params. A summary reports how many elements and parameters were updated, and lists any that could not be written.
Repeating the cycle Whenever P&ID values change, run Export Values or Export All again and then Sync Params. The mapping itself only has to be defined once per project.

9. The Element List

Element List in Revit shows the elements of the supported categories with their level, family, type, category and object ID. Linked rows are marked with a green dot and grouped at the top.

Filtering

Each column header carries a filter arrow. Click it to choose which values to show, in the same way as a spreadsheet filter. A search box narrows long lists, and filtered columns are shown in blue. Clear Filters resets them all. Filters are remembered while the application stays open.

Finding unlinked components

On the Plant 3D side, Show Unlinked selects every component in the current drawing that is not yet linked, so the remaining work is highlighted directly in the drawing.

Deleted objects

If a linked Revit element is deleted, its link is removed automatically so the overview stays accurate. In workshared models this clean-up is deliberately conservative: links are kept rather than removed when an element cannot be found, so nothing is lost while part of the model is not loaded.

10. Working in a team

P&ID Link supports workshared Revit models. When the model you open is workshared, links and mappings are stored in a shared folder beside the central model, so the whole team sees the same links.

Where the shared data is kept

A folder named PIDLink_Data is created next to the central model file. It holds the links, the parameter mappings and the exported P&ID values. Everyone who uses P&ID Link on that project needs read and write access to that folder.

If the folder cannot be created — for example because the project folder is read-only — P&ID Link continues to work using local storage on that computer instead, and the links are simply not shared.

For a model that is not workshared, nothing changes: links stay on your own computer.

Recommended: one person owns the linking

Although links are shared with everyone on a workshared model, it works best if one person is responsible for creating and removing them. Linking is not merged between users: if two people link the same object to different partners, the later link replaces the earlier one without warning.

Everyone on the team can open the Element List, navigate between linked objects and run Sync Params. It is only the creating and removing of links that is best kept with one person.

Points to be aware of

  • The shared folder is found through the Revit model. On a computer where the Revit model has not been opened yet, the Plant 3D side still uses local storage.
  • Sync Params writes to elements in the shared model, so run it deliberately rather than several people at once. Remember to synchronise with central afterwards.
  • If an element is owned by another user, the parameters that cannot be written are reported in the summary at the end of the sync.
  • Links belonging to elements that cannot be found are never removed automatically in a workshared model.
Changing between models The shared location follows the model you have open. Closing a workshared model and opening a single-file model returns P&ID Link to local storage automatically, with no setting to change.

11. Troubleshooting and support

SituationWhat to do
The ribbon tab is missing in Plant 3D Restart Plant 3D so the ribbon is rebuilt. If it is still missing, reinstall for that release.
A command reports that the license could not be verified Connect to the internet, make sure you are signed in to the Autodesk account that acquired P&ID Link, and restart the application.
Link says no object is remembered Both sides must be picked before linking. Use Pick in Plant 3D and Pick Element in Revit, then click Link.
Unlink says the objects are not linked to each other Unlinking requires both sides picked and both belonging to the same pair.
No Plant 3D project is open P&ID Link reads the P&ID project database, so a project must be open, not just a drawing.
Sync reports that a parameter is read-only or missing The Revit parameter must exist on the element and be writable. Check that the shared parameter is loaded and bound to the category.
Sync finds no values Run Export Values or Export All in Plant 3D first.
A colleague cannot see my links Links are shared only for workshared Revit models, through the PIDLink_Data folder beside the central model. Check that everyone has access to that folder.
Plant 3D cannot find a linked drawing The drawing was moved or renamed after the link was created. Restore the file, or unlink and link again.

Where your data is stored

For a workshared Revit model: <central model folder>\PIDLink_Data

Otherwise, and for your own current selection in either application: %LOCALAPPDATA%\PIDLink

Nothing is stored inside the drawing or the model, and nothing is sent anywhere.
